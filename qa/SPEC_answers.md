## Q-SPEC-02: 購入済み解除時に `checkedAt` を null にリセットするか？

**AI 仮定（確定）**: 購入済みを解除した場合、`checkedAt` を null にリセットする。

根拠:
- `checkedAt` は「現在の購入済み状態の購入日時」を表すフィールドであり、未購入に戻れば購入日時は存在しない。
- null リセットが最もシンプルな実装であり、並び順ロジックとも整合する。
- 購入履歴ログを残す要件は本仕様のスコープ外（非機能要件・データ要件に記載なし）。

SPEC.md への反映: Section 8.4「購入済み解除機能」および Section 10「データ要件」に「購入済みを解除した場合、`checkedAt` を null にリセットする」を明記する。
